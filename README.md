# Super_Store_Analysis


# Superstore Sales Analysis using Power BI

## 📌 Project Overview

<img width="489" height="281" alt="Screenshot 2026-10-10 101103" src="https://github.com/user-attachments/assets/eddf0d1f-c293-418d-afee-8d090ea959d1" />


This project focuses on analyzing Superstore sales data using **Microsoft Power BI** to understand sales performance, profitability, product trends, customer segments, geographical performance, and shipping methods.

The interactive dashboards help identify business trends, compare sales and profit across different categories, and generate meaningful insights to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales, profit, quantity, discounts, and order volume.
- Identify the best-performing product categories and products.
- Compare sales and profit across customer segments.
- Analyze geographical performance by city, state, and region.
- Evaluate sales and order distribution across different shipping modes.
- Understand yearly sales and profit trends.
- Present key business metrics through interactive dashboards.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and measures
- **Superstore Dataset** – Data source for sales analysis

## 🚀 How to Use This Project

3. If required, update the dataset source path.
4. Refresh the data.
5. Explore the dashboard pages and interact with the available filters and visuals.
